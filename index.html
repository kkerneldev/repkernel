03 / FAQ

Quick answers.

How does Add to AltStore work?

It opens AltStore Classic using its URL scheme and passes the public URL of your source.json. Set that URL in script.js before publishing.

Can I host this on GitHub Pages?

Yes. Upload the files to the root of your repository, then enable Pages in Settings → Pages and publish from your main branch.

Why is the source list empty?

The included source.json is a starter template. Add valid app entries before using it as a real source.
